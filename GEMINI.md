# Reglas Globales y Directrices del Proyecto - Plataforma HVAC

## 1. Stack Tecnológico Riguroso
Todos los agentes y subagentes deben apegarse estrictamente a las siguientes tecnologías:
- **Framework Opcional**: Next.js 15 utilizando el paradigma App Router.
- **Librería UI**: React.
- **Estilización**: Tailwind CSS.
- **Lenguaje**: TypeScript con tipado estricto (strict mode).
- **Base de Datos**: PostgreSQL hospedado en Render.
- **ORM**: Prisma.
- **Autenticación**: NextAuth.js o Autenticación por Base de Datos.
- **Despliegue**: Render.


## 2. Paradigma de Trabajo
- **Prioridad de Permiso (Permission-First Workflow)**: Bajo ninguna circunstancia alterar el sistema de archivos, ejecutar comandos en la terminal de despliegue, o crear arquitecturas sin autorización explícita utilizando el comando "PLAN APROBADO".
- Si el contexto se vuelve ambiguo, el agente debe pausar y solicitar claridad.

## 3. Directrices de Diseño UI/UX
- **Estilo**: "Moderno y Minimalista".
- **Elementos UI**: Supresión de elementos superfluos.
- **Espaciado**: Uso extensivo de espacios en blanco (negative space).
- **Tipografía**: Fuentes sans-serif limpias de alta legibilidad.
- **Esquema de Colores**: Basado en tonos fríos corporativos para transmitir profesionalismo y frescura, con colores de contraste vibrante para las llamadas a la acción (CTAs) para maximizar la conversión.
- **Fricción**: Las páginas clave deben resolver la necesidad del usuario en un máximo de dos clics.
